Fix: Prompt passed from landing page is displayed in the editor but not automatically processed by the AI.

Project context:
AI-powered Vibe Coding platform (HelpHand). The landing page passes a user prompt to the editor via URL parameter (e.g. /editor?prompt=Создай+сайт+курса+моего+английского). The editor reads this parameter, pre-fills the input, and should automatically submit it to the AI.

Current broken behavior:

User types a prompt on the landing page → gets redirected to the editor
The prompt text appears correctly in the editor input field ✅
BUT the AI does not process it — no response, no generation, nothing happens ❌
If the user then manually types a new message and hits send — the AI works perfectly fine ✅
This means the AI engine itself works, but the auto-submit from the URL parameter is broken


Root cause — most likely a timing/initialization race condition:
The editor component reads the URL parameter and calls the submit function too early — before the AI chat engine, WebSocket connection, or API client has fully initialized. The message is "sent" into the void because nothing is ready to receive it yet.

How to fix:
1. Wait for the AI engine to be fully ready before auto-submitting:

Do NOT call the submit function immediately on component mount (useEffect with empty deps)
Instead, wait for a "ready" signal — for example:

WebSocket onopen event fires
AI client reports status === 'ready'
A specific state variable like isReady, isConnected, or isInitialized becomes true


Only then trigger the auto-submit with the URL prompt

2. Use a useEffect that watches the ready state:
javascriptuseEffect(() => {
  if (isReady && urlPrompt && !hasAutoSubmitted) {
    setHasAutoSubmitted(true);
    handleSubmit(urlPrompt);
  }
}, [isReady, urlPrompt]);

isReady — true when AI/WebSocket is fully initialized
urlPrompt — the prompt read from URL parameter
hasAutoSubmitted — a flag to prevent submitting more than once

3. Add a fallback timeout:

If isReady never becomes true within 5 seconds, show a visible error message:
"Не удалось подключиться к AI. Пожалуйста, отправьте запрос вручную."
Pre-fill the input so the user can just press send without retyping

4. Do NOT use setTimeout with a fixed delay as the main solution:

A hardcoded setTimeout(submit, 1000) is unreliable — connection can take longer on slow networks
Always tie the auto-submit to the actual ready state, not an arbitrary delay

5. Verify the submit function receives the correct format:

When calling handleSubmit(urlPrompt) automatically, make sure it receives the same data format as when the user manually types and clicks send
Some submit handlers expect an event object (e.preventDefault()) — make sure this is handled when calling programmatically
