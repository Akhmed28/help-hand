Fix: User prompt is not being passed from the landing page to the editor.
Current broken behavior:

User types or speaks a prompt on the landing page (e.g. "создать сайт")
User clicks the "Создать сайт" / "Готово" button
User is redirected to the editor/IDE page
BUT the prompt is empty in the editor — the user has to type it again manually

Expected correct behavior:

User enters a prompt on the landing page
User clicks the button to proceed
User is redirected to the editor/IDE
The prompt from the landing page is already pre-filled and automatically submitted in the editor — no need to type it again


How to fix:

Pass the prompt via URL parameter:

When the user clicks the button on the landing page, take the input value and append it to the redirect URL
Example: redirect to /editor?prompt=создать+сайт


Read the parameter in the editor:

On the editor page, on load, check if a prompt query parameter exists in the URL
If it exists — pre-fill the editor input field with that value
Automatically trigger the generation/submit function as if the user had typed it and pressed enter


Handle voice input the same way:

If the prompt was entered via microphone (speech-to-text), treat the transcribed text exactly the same as typed input
Pass it through the same URL parameter flow


Edge cases to handle:

If the prompt parameter is empty or missing — editor opens normally with empty input
URL-encode the prompt text properly to handle spaces and special characters
If the editor uses a router (React Router, Next.js, etc.) — use the appropriate method to read query params (useSearchParams, useRouter, $route.query, etc.)



Do not change:

Any other functionality of the landing page or editor
Backend logic or API calls
Styling or layout
